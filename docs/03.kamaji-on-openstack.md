# [OpenStack Infra Provider](https://kamaji.clastix.io/cluster-api/openstack-infra-provider/)
Use the "Cluster API OpenStack Infra Provider (CAPO)" with the Cluster API Kamaji Control Plane Provider to create Kubernetes clusters.

## Prerequisites
* kind, kubectl, clusterctl, openstack CLI, openssl, and base64
* Host images built with "image-builder" (or equivalent) and configured with cloud-init using the OpenStack datasource
* An existing OpenStack environment with network connectivity, flavors, host images for control plane and worker nodes
* OpenStack load balancer support (Octavia) for Service type LoadBalancer and API endpoint/public IP management for the kubeadm-based control plane cluster

## Setup management cluster
Install management cluster as [installation guide](./02.mgmt-cluster.md)

#### Install providers
Install ORC before initializing Cluster API providers:

```bash
export ORC_VERSION=v2.0.3

k apply -f "https://github.com/k-orc/openstack-resource-controller/releases/download/${ORC_VERSION}/install.yaml"
# Pulling image "quay.io/orc/openstack-resource-controller:v2.0.3"

k get pod -n orc-system
    NAME                                      READY   STATUS    RESTARTS   AGE
    orc-controller-manager-55fb4889fd-7hb8s   1/1     Running   0          98s
```

Enable feature gates required by KamajiControlPlane.spec.deployment.externalClusterReference:
```bash
kubectl -n kamaji-system patch deployment capi-kamaji-controller-manager --type='json' \
  -p='[
    {
      "op": "replace",
      "path": "/spec/template/spec/containers/0/args/1",
      "value": "--feature-gates=ExternalClusterReference=true,ExternalClusterReferenceCrossNamespace=true"
    }
  ]'
```

### Prepare OpenStack application credentials
Application credentials are created in the currently `"scoped project"`.

Set `TARGET_PROJECT_ID` explicitly so credential creation is project-scoped.
```bash
export OPENSTACK_CLOUD_NAME=openstack-stage
export TARGET_PROJECT_ID=214fda0be59747cdb5efb5e9f6347000
export OPENSTACK_APP_CREDENTIAL_NAME=capi-kamaji
export OPENSTACK_APP_CREDENTIAL_SECRET="$(openssl rand -hex 12)"
```
create application credential:
```bash
openstack application credential create --os-project-id "$TARGET_PROJECT_ID" --secret "$OPENSTACK_APP_CREDENTIAL_SECRET" "$OPENSTACK_APP_CREDENTIAL_NAME"

export OPENSTACK_APP_CREDENTIAL_ID=$(openstack --os-project-id "$TARGET_PROJECT_ID" application credential show "$OPENSTACK_APP_CREDENTIAL_NAME" -f value -c id)
```

Update `env.sh` file for enviroment variable used in manifest
```bash
cd ~/kaas/kamaji/openstack-infra-provider
vim env.sh
```

## Bootstrap the Control Plane Cluster
### Generate manifest based on enviroment variable:
```bash
cd ~/kaas/kamaji/openstack-infra-provider
./render-cp.sh
```

### Apply cluster resources
```bash
cd ~/kaas/kamaji/openstack-infra-provider/manifest

k apply -f helm.yaml
k apply -f control-plane-secret.yaml
k apply -f control-plane-cluster.yaml
```

check logs:
```bash
stern -n capo-system capo-controller-manager
stern -n capi-system capi-controller-manager
```

### Verify control plane cluster
```bash
source ~/kaas/kamaji/openstack-infra-provider/env.sh
clusterctl describe cluster "$CONTROL_PLANE_CLUSTER_NAME" -n "$CLUSTER_NAMESPACE"
```

if everything is find, output will be like:

